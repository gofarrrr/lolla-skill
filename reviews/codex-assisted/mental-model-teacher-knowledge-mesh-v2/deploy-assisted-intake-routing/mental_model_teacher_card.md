# The Thinking Move

This teaches the reasoning move behind the case; it is not judging whether the decision was correct.

Sort the situation into buckets before deciding what each bucket needs.

# Why It Mattered

It stopped one big recommendation from flattening different decision types into the same treatment. The boundary lens added: Separate the reversible experiment from the irreversible commitment.

# How The Models Work Together

Plain teaching: one lens protects the user from overload; the other protects the user from closing options too early. Use them as a calibration exercise: keep the smallest set of options that still buys learning. Relationship label: structured tension pair.

# The Model Stack

- Sort The Case Before Judging It: When repeated decisions are vulnerable to inconsistent in-the-moment exceptions, use category decisions to define stable buckets and boundaries before evaluating individual cases, while checking that the category still matches the underlying situation.
- Reduce The Thinking Burden: When complexity, stress, or presentation design is overloading working memory, simplify sequence and format so attention goes to the next useful distinction while preserving the causal cues needed for correct action.
- Preserve A Cheap Test: When an important decision has collapsed into a do-or-do-not frame, separate invention from evaluation: generate at least three viable options, then compare benefits, costs, payoffs, and probabilities before choosing.

# Practice It

## Sort The Case Before Judging It

1. Name the tempting first read.
2. Which category does this part belong to, and does that category need a different rule?
3. Name the boundary that would change confidence.

Answer criteria:
- The answer names the tempting one-size-fits-all read.
- The answer sorts the situation into concrete buckets before judging it.
- The answer gives at least one bucket a different rule, threshold, or next step.

Worked example:

- Weak first read: The feature has enough gates, so the whole deployment can be judged as one decision.
- Better question: Which parts are reversible experiments, irreversible commitments, operator burden, and patient-risk controls?
- Stronger answer: Sort each part first, then give irreversible or patient-risk buckets stricter thresholds while keeping reversible learning cheap.

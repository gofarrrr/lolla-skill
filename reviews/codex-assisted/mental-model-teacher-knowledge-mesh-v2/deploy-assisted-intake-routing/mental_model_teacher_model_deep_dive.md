# When Not To Use It

Limitations and Anti-Patterns 1. **Maslow’s Hammer (The Law of the Instrument):** The model’s biggest limitation is the inherent risk of over-reliance on familiar categories. This bias occurs when **"the only tool you have is a hammer, [so you] treat everything as if it were a nail"**. This can lead problem-solvers to persist in using categorical frames that are **unhelpful or misleading in the new and different context**. This false pattern recognition risks **disastrously wrong solutions**. 2. **Useless Accuracy:** Category Decisions necessarily simplify reality. If the categorization is too exhaustive or focuses on excessive details, it can become accurate but useless. # Dangerous Misuse

Failure Modes and Cognitive Biases 1. **Tool-Centric Solutions:** A reliance on predefined categories risks having the solution dictated by the tool rather than the problem. When taking a problem to an expert, you should expect an approach that can be solved with the **expert’s toolkit**, not necessarily the overall best solution. This stems from the substitution bias where a known, simple model is used instead of understanding the complicated actual model. 2. **Loss of Focus due to Clutter:** When compiling context or data for a decision, saturating the prompt or document with too much loosely relevant content—even if categorized—can distract the user or the underlying model. This is a failure to exercise **focus over comprehensiveness**. 3. **The Curse of Knowledge (Expert Blind Spot):** An expert, having internalized the categorical structure (a mental edifice), fails to communicate.

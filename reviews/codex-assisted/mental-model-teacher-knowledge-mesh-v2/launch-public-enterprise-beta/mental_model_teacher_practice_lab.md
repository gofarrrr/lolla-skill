# Mental Model Teacher Practice Lab

Status: passed

## The Rep

Ask what evidence remains if the authority signal is removed.

## Exercises

### Test The Authority, Not The Aura

Ask what evidence remains if the authority signal is removed.

Steps:
1. Name the tempting first read.
2. If the impressive source disappeared, what evidence would still justify this?
3. Name the boundary that would change confidence.

Answer criteria:
- The first read is stated in plain language.
- The answer names evidence, not vibes or status.
- The answer includes a confidence-changing boundary.

Common failure mode:

The rep becomes a decision recommendation instead of reasoning practice.

### Explain The Model Pair

Authority Bias and First Principles Thinking form an antagonist pair. First principles thinking strips away inherited doctrine and forces a return to core facts when expert prestige is doing too much work. Use the pair as a correction loop: Authority Bias names the pull that can dominate the first interpretation, while First Principles Thinking asks what would remain if that pull stopped counting as proof.

Steps:
1. Write one sentence for what authority-bias sees.
2. Write one sentence for what first-principles-thinking sees.
3. Name why the pair is an antagonist.

Answer criteria:
- Each lens gets a different job.
- The relation type is explained without only naming it.
- The answer says what would be missed if only one lens were used.

Common failure mode:

The answer lists model names but does not explain the relation.

### Stop Before Fake Certainty

Do not call this model noise or imply it was adjudicated.

Steps:
1. Name what the lesson is allowed to teach.
2. Name what the lesson is not allowed to claim.
3. Name one missing fact that would change how strongly you use the model.

Answer criteria:
- The answer refuses to claim decision correctness.
- The answer names a concrete missing fact or condition.
- The answer keeps the model useful without making it universal.

Common failure mode:

This lesson does not prove the original answer was wrong or the revised answer was right.

## Completion Check

You are done when:
- You can name the tempting first read.
- You can explain which lens expands the question.
- You can explain which lens creates the boundary.
- You can state what evidence would change confidence.

You are not done when:
- You only repeat the model names.
- You convert the exercise into a recommendation.
- You ignore the boundary or non-claim.

## Boundary

This lab trains a reasoning pattern. It does not prove the original answer was wrong or the revised answer was right.

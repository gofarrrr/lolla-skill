# The Thinking Move

This teaches the reasoning move behind the case; it is not judging whether the decision was correct.

Ask what evidence remains if the authority signal is removed.

# Why It Mattered

It made deference visible so the user could separate evidence from confidence, role, or prestige. The boundary lens added: Break the recommendation down to the facts and constraints that must be true.

# How The Models Work Together

Plain teaching: one lens names the pull of status, polish, or expert authority; the other lens strips the situation back to facts that would still matter without that authority. Use them as a correction loop before trusting the first confident recommendation. Relationship label: antagonist pair.

# The Model Stack

- Test The Authority, Not The Aura: When a recommendation depends on authority, make the deference explicit, verify expertise, trustworthiness, domain fit, and track record, then require the authority's reasoning and override evidence so rank or polish accelerates triage without replacing falsification.
- Ask Who Knows What: When the party being evaluated controls dashboards, references, pilots, or reported outcomes, treat the visible evidence as part of the asymmetry: name what the party can choose or game, identify the hidden payoff it may optimize, and require an independent signal or direct observability before commitment.
- Strip It Back To First Principles: When inherited categories or conventional rules are distorting the problem, strip the case to facts and desired outcome, identify what would have to be true for a novel path to work, and rebuild toward concrete action without using first-principles language as status theater.

# Practice It

## Test The Authority, Not The Aura

1. Name the tempting first read.
2. If the impressive source disappeared, what evidence would still justify this?
3. Name the boundary that would change confidence.

Answer criteria:
- The answer names the authority, status, or polish pressure without treating it as proof.
- The answer separates independent evidence from the aura around the source.
- The answer states one concrete boundary that would change confidence.

Worked example:

- Weak first read: The enterprise prospect is impressive, so the launch pressure must be strategically important.
- Better question: If the enterprise logo disappeared, what independent evidence would still justify this path?
- Stronger answer: Look for paid commitment, scoped success criteria, buyer access, operator access, and a reversible pilot boundary before treating the prospect as evidence.

## Cold-Reader Lesson Path

1. Start with the case only as an anchor.
   The case creates a reasoning pressure: It made deference visible so the user could separate evidence from confidence, role, or prestige. Break the recommendation down to the facts and constraints that must be true. Ask what evidence remains if the authority signal is removed.
2. Name the thinking move.
   Ask what evidence remains if the authority signal is removed.
3. Check whether the model relationship teaches something reusable.
   Plain teaching: one lens names the pull of status, polish, or expert authority; the other lens strips the situation back to facts that would still matter without that authority. Use them as a correction loop before trusting the first confident recommendation. Relationship label: antagonist pair.
4. Try the practice rep before judging polish.

Practice title: Test The Authority, Not The Aura

- Name the tempting first read.
- If the impressive source disappeared, what evidence would still justify this?
- Name the boundary that would change confidence.

Answer criteria:

- The answer names the authority, status, or polish pressure without treating it as proof.
- The answer separates independent evidence from the aura around the source.
- The answer states one concrete boundary that would change confidence.

Worked micro-answer:

- Weak first read: The enterprise prospect is impressive, so the launch pressure must be strategically important.
- Better question: If the enterprise logo disappeared, what independent evidence would still justify this path?
- Stronger answer: Look for paid commitment, scoped success criteria, buyer access, operator access, and a reversible pilot boundary before treating the prospect as evidence.
- Confidence boundary: The lesson would weaken if those independent signals were already present and the authority signal was only a shortcut to them.

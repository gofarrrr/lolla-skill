## Practice Rep

- Prompt: Choose one active decision and write the reference class before listing the details that make it feel special.
- User action: Write a prior, then add the local evidence as an update rather than a replacement.

## Do Not Overlearn

- Do not assume the prior settles the decision.
- Do not treat a weak reference class as discipline.

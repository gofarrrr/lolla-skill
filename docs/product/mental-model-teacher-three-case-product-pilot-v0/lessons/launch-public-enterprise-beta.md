# Ask what evidence remains if the authority signal is removed.

Product framing: case is the anchor; reasoning move is the subject; model relationship is the lesson; practice rep is the product value.

Case: `launch-public-enterprise-beta`

## Case Anchor

The original answer looked coherent enough to accept. It made deference visible so the user could separate evidence from confidence, role, or prestige. Break the recommendation down to the facts and constraints that must be true. Ask what evidence remains if the authority signal is removed.

## Model Stack

- [Test The Authority, Not The Aura](../../../../reviews/codex-assisted/mental-model-teacher-knowledge-mesh-v2/launch-public-enterprise-beta/okf/mental_model_teacher/models/authority-bias.md) - `primary_teaching_lens`: When a recommendation depends on authority, make the deference explicit, verify expertise, trustworthiness, domain fit, and track record, then require the authority's reasoning and override evidence so rank or polish accelerates triage without replacing falsification.
Boundary: Credibility is standing in for falsification, evidence testing, or domain-boundary checks.
- [Ask Who Knows What](../../../../reviews/codex-assisted/mental-model-teacher-knowledge-mesh-v2/launch-public-enterprise-beta/okf/mental_model_teacher/models/information-asymmetry.md) - `primary_teaching_lens`: When the party being evaluated controls dashboards, references, pilots, or reported outcomes, treat the visible evidence as part of the asymmetry: name what the party can choose or game, identify the hidden payoff it may optimize, and require an independent signal or direct observability before commitment.
Boundary: The critical evidence is externally audited, directly observable in production, or contractually hard for one side to manipulate.
- [Strip It Back To First Principles](../../../../reviews/codex-assisted/mental-model-teacher-knowledge-mesh-v2/launch-public-enterprise-beta/okf/mental_model_teacher/models/first-principles-thinking.md) - `boundary_lens`: When inherited categories or conventional rules are distorting the problem, strip the case to facts and desired outcome, identify what would have to be true for a novel path to work, and rebuild toward concrete action without using first-principles language as status theater.
Boundary: First principles is being used as a status move to ignore practical constraints, accumulated know-how, or real implementation costs.

## Relation Story

Authority Bias and First Principles Thinking form an antagonist pair. First principles thinking strips away inherited doctrine and forces a return to core facts when expert prestige is doing too much work. Use the pair as a correction loop: Authority Bias names the pull that can dominate the first interpretation, while First Principles Thinking asks what would remain if that pull stopped counting as proof.

## Worked Example

- Weak first read: The enterprise prospect is impressive, so the launch pressure must be strategically important.
- Better question: If the enterprise logo disappeared, what independent evidence would still justify this path?
- Stronger answer: Look for paid commitment, scoped success criteria, buyer access, operator access, and a reversible pilot boundary before treating the prospect as evidence.

## Practice Rep

- Prompt: Test The Authority, Not The Aura
- User action: Name the tempting first read. If the impressive source disappeared, what evidence would still justify this? Name the boundary that would change confidence.

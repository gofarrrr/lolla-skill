## What this means

Independent semantic role calls can each produce coherent and useful interpretations while still overlapping in a way the product contract rejects. More wording changes are no longer justified by the evidence. Deterministic alias subtraction is also rejected because one sentence can legitimately contain both an adopted condition and an unresolved matter.

The next decision is architectural but bounded: determine whether current and qualification should receive limited probabilistic cross-role context or be reconciled in one small semantic task. Any proposal must preserve source evidence, speaker ownership, uncertainty, no semantic scoring, no keyword gates, and a controlled call budget. It must first be tested provider-free.

# Conversation-state microtask probe v1

This package contains the founder-authorized, prospectively frozen Case 02
microtask experiment.

- `contract.json`: exact case, prompts, schemas, model, order, budget, locks,
  scoring, and stop rules;
- `call-authorization.json`: one-time authorization for at most three calls;
- `positions-result.json`: accepted provider inference whose candidates were
  semantically and mechanically quarantined;
- `threads-result.json`: HTTP 400 provider rejection before inference;
- `source-review.json`: source-first per-family review;
- `decision.json`: closed status and next boundary;
- `result.md`: plain-language interpretation.

There is intentionally no `constraints-result.json`: the second call failed
operationally and the frozen stop rule prohibited the third call.

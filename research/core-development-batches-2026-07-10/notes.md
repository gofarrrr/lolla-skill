## Batch 3 — fact/reasoning boundary invariance shadow

### Design and freeze

This batch does not ask whether a second answer is better. It tests the more basic
architectural claim that facts can remain in the authoritative audit record while a
narrow, fact-free reasoning projection is the only input to deterministic seed
routing.

Three synthetic fixtures are frozen:

1. `facts_a`: ambiguous demand is treated as commitment evidence and operating
   constraints are acknowledged but not made decision gates;
2. `facts_b`: the same reasoning mechanics with different industry, actors,
   quantities, currency, dates, and labels;
3. `mechanism_changed`: the same facts as `facts_a`, but the advice separates
   hypotheses and makes transition constraints explicit gates.

The LLM receives the complete conversation and may select only from a ten-item
controlled mechanism vocabulary. Deterministic code then validates the exact
shape and turn references, removes all case context from the routing projection,
and maps controlled mechanism IDs to declared V60 seed model IDs. No graph
expansion or live runtime modification occurs.

## Batch 4 — integration and simplification decision

Decision: retain the current live core as experimental; keep SK3 overlay,
portfolio expansion, and fact-free pattern routing offline/shadow. Do not
promote or expand the graph path.

Reasons:

- Batch 1 showed a real directional treatment contribution but failed a shared
  unsupported-claim red line;
- Batch 2 showed correct public stand-down and private consideration but
  failed exact pressure identity and effect custody;
- Batch 3 showed that deterministic fact-free sealing is viable while the LLM
  abstraction is not yet invariant or well-targeted;
- earlier strong-control evidence shows that a fresh transcript-only reasoner
  often recovers obvious corrections, so Lolla must earn incremental or
  accountable-consideration value rather than merely produce a better-looking
  second answer.

Next work is a fixed development program: exact pressure-custody hardening,
joint-process routing-target clarification using existing evidence, one new
prospectively frozen paired holdout, new (not reused) invariance pairs, then a
minimal promotion-or-simplification recheck.

Batch 4 status: **complete; research-only decision for new semantic/graph
integration, with continued focused development authorized**.

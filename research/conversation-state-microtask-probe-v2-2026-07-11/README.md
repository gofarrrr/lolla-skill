# Conversation-state microtask probe v2

This package preserves the authorized Case 05 strict-schema transfer attempt.
The first provider call failed before inference and the stop rule prevented the
remaining two calls.

- `contract.json`: frozen repair, transfer selection, schemas, order, and gates;
- `call-authorization.json`: exact one-time authorization;
- `pre-provider-runner-failure.json`: zero-call wrapper-label failure;
- `threads-result.json`: provider HTTP 400 artifact;
- `source-review.json`: no-semantic-observation boundary;
- `decision.json`: closed decision and recommended JSON-mode boundary;
- `result.md`: plain-language result.

There are intentionally no constraints or positions result files.

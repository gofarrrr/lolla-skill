## Question

After first-class `no_rendered_handoff.v1` and decline-evaluation slices, is a
tiny off-default candidate-generator contract earned?

Decision:

```text
not yet
```

Run one more static decline/control replay first, preferably in a non-safety /
non-counsel case shape.

## First Principles

The product boundary in `HOW_IT_WORKS.md` is clear:

```text
Lolla produces structural counter-pressure, not replacement answers.
Lolla produces findings, not answers.
The downstream model or human decides what to do with the pressure.
LLMs belong at semantic/generative edges.
Deterministic code belongs in custody, provenance, routing, validation, and assembly.
```

So the object being researched here is not a generator of advice.

The safest name for the future object, if it ever exists, is:

```text
pressure-transport admission layer for off-default evaluation
```

Its only question would be:

```text
Is there a private pressure surface worth preparing for Step 6 to consider?
```

It must not answer:

```text
What should the final advice be?
Which pressure is true?
Which arm is correct?
What should Step 6 believe?
```

Step 6, a Codex/Claude-style downstream reasoner, or the human remains the
judgment layer.

## What The Last Two Slices Earned

The last two slices were healthy because they made decline first-class.

`no_rendered_handoff.v1` now proves:

```text
decline can be represented as a small research artifact
decline can carry source refs and a short receipt
decline can block runtime/product/generator promotion
decline can reject hidden answer-plan language
```

`pre_step6_decline_evaluation.v1` now proves:

```text
decline can be evaluated without requiring the rendered candidate it withheld
the simpler raw/control path can be used as evaluation evidence
medium naturalness debt avoided can be recorded
generator implementation can remain blocked after a healthy decline
```

These are real primitives.

They do not prove:

```text
decline generalizes beyond the consultant safety/counsel archetype
a future admission layer can find decline cases
a generator contract is ready
runtime should change
product docs should change
```

## Why Not Generator-Contract Work Yet

The current healthy decline evidence is strong but narrow.

The case shape is:

```text
high-stakes consultant situation
counsel-first preservation
safety / legal-adjacent restraint
main risk is over-processing
control/raw remains enough
```

That is useful, but it is a very particular archetype. If generator-contract
work starts now, the contract may overfit decline to:

```text
counsel-first cases
safety-first cases
expert-first restraint cases
```

That would be the wrong lesson.

The deeper question is whether `no_rendered_handoff` is a general
pressure-transport decision:

```text
no important pressure would be lost
rendered would add naturalness debt
simpler path remains sufficient
reactivation conditions are clear
```

We need one more case shape before drafting even a small generator contract.

## Language Discipline

Future research artifacts should avoid answer-adjudication phrasing such as:

```text
correct move
correct answer
control is best
answer should
final advice should
```

Preferred vocabulary:

```text
simpler path remains sufficient for pressure transport
no pressure-transport reason observed
handoff not needed here
rendered would add naturalness debt without enough pressure lift
reactivate if a live pressure is lost
Step 6 remains the judgment layer
```

This is not cosmetic. The language keeps deterministic custody from drifting
into answer selection.

## Future Admission Layer Boundary

If a future candidate generator is ever specified, it may:

```text
prepare a private candidate pressure surface for evaluation
decline and leave a small receipt
validate refs, caps, modes, hygiene, and promotion blocks
record naturalness-debt risk
record reactivation conditions
stay off-default and evaluation-only
```

It may not:

```text
decide final advice
decide which pressure is true
force Step 6 to use rendered material
turn naturalness debt into a deterministic score
turn decline conditions into a classifier formula
create new handoff modes
launch workers
build bundles
promote runtime behavior
```

## Next Slice

Run one more static decline/control replay in a different case shape.

Selection criteria:

```text
non-safety / non-counsel case
simpler control/raw path plausibly sufficient
rendered might add nuance but risks naturalness debt
no obvious high-clutter dependency pressure
no obvious unresolved two-sided conflict that rendered is likely to preserve
the case can produce a small no_rendered_handoff receipt
```

Good candidate direction:

```text
a strategic or academic case where the answer needs calm prioritization more
than extra pressure transport
```

Avoid:

```text
another legal/counsel/safety restraint case
another founder high-clutter case
another PhD-style unresolved conflict case
```

Pass condition:

```text
the replay can honestly record healthy decline, retest, or missed decline
without bending schema or treating rendered absence as error
```

Kill condition:

```text
the only way to make the slice useful is to smuggle answer-selection language
or deterministic scoring into the decline receipt
```

## PM Verdict

The recent work is aligned with Lolla only if it remains custody and admission
research.

The next evidence should slow the generator impulse, not feed it. One more
static decline/control replay in a different case shape is the right brake
before any generator-contract work.



the same judgment-led review on a known healthy-decline case. If reviewers
cannot recommend no handover where no handover already looks healthy, then the
reviewer protocol is itself pressure-amplifying.

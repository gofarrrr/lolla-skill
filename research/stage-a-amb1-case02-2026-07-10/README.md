# Ambiguous development Case 02 — Stage A

This package runs the existing full private Lolla pressure pipeline on
`amb1-case02-nonprofit-scale`, the first case in the frozen designed-ambiguity
development rank.

The source is synthetic and was authored by Codex in the same project session.
It is useful for development and failure discovery, but it is not an independent
holdout and cannot establish causal or real-world product value.

Before the run, see `selection-contract.json`, `contract.json`,
`call-authorization.json`, and `preflight.md`. After the run, this package must
preserve the raw execution artifacts, sealed gate artifacts, and a source-first
pressure review. A passed pipeline only proves the bounded machinery completed;
it does not prove that the pressure is useful.

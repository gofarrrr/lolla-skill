# Lolla Evidence Gates

Read this reference when a proposed change touches conversation meaning,
mental-model selection, graph traversal, receipts, Decision Trail, Decision
Work, or a connection between them.

## One system, five authority layers

```text
available conversation prose
  authoritative source custody, bounded capture
        |
        v
provisional conversation interpretation
  LLM-authored meaning with exact source links and omissions
        |
        v
curated mental-model graph and pressure planner
  deterministic identity, direction, bounds, traversal, active/reserve custody
        |
        v
reconsidering reasoner
  apply / reject / park
        |
        v
archive, receipt, Decision Trail, Decision Work, Observatory
  process evidence and bounded projections, never action authority
```

The layer after an error cannot certify the layer before it. A deterministic
graph path cannot prove that the conversation was interpreted correctly. A
complete receipt cannot prove that selected pressure was useful. A polished
interface cannot prove that a revised answer was better.

## Current graph boundary

The repository owns 222 canonical Markdown models and 1,358 curated directed
relations. One deterministic compiler can reconstruct the published compact
and rich graph artifacts. One immutable reader owns publication identity,
canonical lookup, source custody, and outgoing, incoming-reference, and
incident indexes. One versioned planner owns the live policy:

- up to six direct-active models;
- expansion seeds: direct active only;
- authored outgoing direction only;
- exactly one hop;
- antagonist, tension, and ally slots;
- deterministic order and deduplication;
- bounded active and reserve custody;
- graph pressure survives upstream probabilistic filtering;
- provider calls: zero for planning and traversal.

The reader's ability to expose incoming references is not permission to use
them as live pressure. Incident lookup is not a reciprocal relation. A
two-edge path is not a new relation or transitive truth.

## Current conversation-understanding boundary

Lolla strongly preserves source and process facts: transcript bytes, hashes,
bounded extraction views, provider requests/responses, graph paths,
dispositions, health, privacy, cost, and archives.

It does not reliably generate a longitudinal semantic table of contents for
arbitrary conversations. User/assistant influence, adoption versus
acknowledgment, changes of mind, option lifecycle, values, stakeholders,
unresolved matters, and lost value remain provisional, human-review dependent,
or unavailable.

The June Decision Trail specialist program stopped after three Codex-assisted
candidate reads. PR104's principal-human correction fields remain blank. The
July Stage 1 option is a separate checked-in-safe labeling review; it cannot
validate those reads or semantic understanding.

## The A/B/C product boundary

### A. Pressure now

Treat the current experimental product as:

```text
preserve conversation
  -> introduce traceable pressure
  -> reconsider
  -> record dispositions and process
```

Use “process receipt,” not “proof the answer is wise.” Keep bounded sidecars
and read-only projections. Evaluate pressure usefulness separately from
semantic fidelity.

### B. Understand later

Resume at PR104 only when a principal human can review the three candidate
reads source-first. The human may correct, reject, simplify, or mark a field
unavailable. Do not fill the gap with another AI reader, guessed private
context, R4, or more sidecar machinery.

### C. Improve the conversation-to-graph bridge

Before changing traversal, test whether the semantic input gives the current
graph a fair problem. Freeze source-linked reasoning roles or mechanisms,
retain their uncertainty, remove case facts only for controlled graph recall,
then reattach the facts before reconsideration. Compare the current outgoing
one-hop policy with a named control. Measure:

- semantic fidelity;
- distinct useful pressure;
- forced associations;
- cognitive load;
- provenance quality;
- apply/reject/park dispositions;
- answer-level value and lost value.

If a specific miss appears, test exactly one alternative: incoming references,
direct-reserve expansion, or bounded two-edge paths. Do not bundle them into
“global graph intelligence.” Live promotion remains a separate decision.

## Decision table

| Finding | Allowed next move | Forbidden inference |
|---|---|---|
| Missing source/compiler custody | Repair the existing ownership chain | Add traversal to compensate |
| Semantic input misreads the conversation | Human-correct or redesign the input contract | Blame one-hop depth |
| Current graph finds no additional useful pressure | Preserve no-graph result or stop | Force graph use |
| Named useful lens is missed under a fair input | Freeze one alternative traversal experiment | Enable all incoming/multi-hop paths |
| Path custody is incomplete | Extend candidate custody without changing selection | Claim more paths are more useful |
| Receipt labels overstate authority | Correct labels/missingness | Claim semantic generation improved |
| Human review unavailable | Preserve pause and unavailable state | Substitute maintainer or AI agreement |

## Parallel-system traps

Do not add:

- another graph compiler or publication loader;
- another planner hidden inside a caller;
- keyword, chronology, or turn-count rules for semantic roles;
- a new automatic Decision Work meaning supplier without human evidence;
- a graph database or MCP connection merely to reproduce current local
  traversal;
- a queue, resolver, or interface before a trustworthy semantic supplier and
  human workflow exist;
- receipt fields that imply relevance, causation, answer quality, or action
  permission.

## Minimum experiment contract

Freeze before execution:

- one question and one causal change;
- exact source cases and hashes;
- source-first target or human rubric;
- semantic packet/schema and omission behavior;
- current-policy identity and one named control;
- deterministic candidate ordering and bounds;
- separate evidence dimensions and nonclaims;
- provider/model/call/cost ceiling, including zero;
- retry, fallback, and stop rules;
- result and decision-record paths;
- explicit live-promotion exclusion.

If any item is unavailable, record it as unavailable. Do not repair meaning
deterministically or silently widen the contract.
